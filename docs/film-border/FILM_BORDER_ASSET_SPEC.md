# Film Grain Studio 胶片边框素材规范（用户导入 v1.3）

本规范是「添加边框 → 导入」的格式及几何约束。**适用于自制和自定义导入的 PNG**。同一份素材可用于覆盖式和外扩式。

## 1. 文件格式（必须通过导入校验）

| 项目 | 规则 |
| --- | --- |
| 画布 | **1920 × 1080 px**（此画布尺寸仍固定，与视频输入/输出分辨率无关） |
| 像素 | 8-bit RGBA PNG，真实 Alpha 通道，PNG color type 6、depth 8 |
| PNG 容器 | 单帧、非 APNG、非隔行；完整 IHDR、IDAT、IEND；不含尾随数据 |
| 最大体积 | 32 MiB（33,554,432 字节） |
| 视频画窗宽高 | 按齿孔方向填写，见下表。成功导入的上一组宽高按方向分别记忆 |
| 画窗位置 | 始终居中，左上角 `x=(1920-宽)/2`、`y=(1080-高)/2`；奇数尺寸会按实际像素坐标取整，并在编码时按像素格式偶数对齐 |
| 画窗 Alpha | **允许 0–255**：Alpha=0 完全透明，1–254 半透明，255 完全不透明。局部刮痕、字样可不透明，但画窗内**超过95%面积完全不透明**将拒绝，以免遮住原视频 |
| 可见边框 | 所选画窗之外至少 **1024 个像素 Alpha≥64**；拒绝仅有画窗滤色、没有任何边框的文件 |

| 齿孔方向 | 画窗宽度（px） | 画窗高度（px） | 新建默认 |
| --- | --- | --- | --- |
| 左右齿孔 `SIDE` | 1600–1780 | 900–1020 | 1688×970 |
| 上下齿孔 `TOP_BOTTOM` | 1600–1910 | 700–860 | 1880×780 |

按像素尺寸导出。PNG 的印刷 DPI 不影响外扩纹理，96 DPI 和 300 DPI 都可使用。

校验器逐像素检查中央画窗的不透明覆盖比例、边框可见像素，保留 RGBA 原图；不会清空或覆盖用户设计的半透明区域。

**透明度建议（不是额外限制）：** 整体轻度染色宜用 Alpha 16–96；颗粒可使用局部随机色块和不同 Alpha；强烈调色层可适当增大 Alpha。**PNG 纹理是静态图层**：动态效果由 FGS 生成。覆盖式的画窗和边框一起晃动，外扩式只移动边框，单张 PNG 不会生成逐帧随机颗粒。此方式是 RGBA 叠加，不等同于三维 LUT 调色。

## 2. 画窗尺寸与坐标示例

| 宽 × 高 | 左上角 (x,y) | 画窗右/下边界（不含） |
| --- | --- | --- |
| 1688 × 970（左右齿孔默认） | (116,55) | (1804,1025) |
| 1880 × 780（上下齿孔默认） | (20,150) | (1900,930) |
| 1680 × 748（旧素材兼容） | (120,166) | (1800,914) |

边框字样、齿孔和片基通常位于所选画窗外；边缘柔化、划痕、暗角、染色、胶片颗粒可延伸到中心画窗并用半透明混合。

制作时建议绘图软件使用 sRGB，透明背景，按所选画窗辅助线绘制。允许通过 Alpha 渐变制作片边柔化；**不再要求中心全部 Alpha=0**。PNG 的主体色彩按照 sRGB 纹理进入现有 SDR/HDR 合成路径，HDR→SDR GPU 预览路线仍属于延期任务。

## 3. 导入流程和存储

1. 在 Photoshop/GIMP/Krita 等绘图工具制作单张 1920×1080 RGBA8 PNG。
2. 选择「添加边框 → 导入」选中 PNG。
3. 填写**边框名称**（默认 PNG 文件名，不含扩展名；必填、最多40字符），设置**画窗宽度/高度**（先选齿孔方向，再按第 1 节的范围填写）。
4. 点击「导入」；FGS 验证图像、生成 RGBA 缓存及画窗尺寸记录。下拉菜单出现「自定义 · 名称 · 静态 / 动态」。成功导入后，将本次宽高记入全局配置，下次导入自动预填；取消或导入失败不更新这两项记忆。

```text
Utils/_FilmBorders/User/
  <32位GUID>.png        # 原 PNG 副本（不修改 Alpha 或图案）
  <32位GUID>.raw        # FGS 生成的 RGBA 缓存
  <32位GUID>.label      # UTF-8 描述名
  <32位GUID>.aperture   # UTF-8：宽<TAB>高<TAB>方向
```

同一素材的静态/动态共用这些文件，运动幅度、速度、随机频率由 FGS 独立设置。取消导入不会创建文件；删除用户样式会同时移除对应 PNG/RAW/label/aperture。内部 GUID 用于唯一标识和输出文件名，列表显示描述名。

**兼容旧版。** 已导入的素材可直接选用。旧版两列 `.aperture` 按宽 1630–1730、高 698–798 的区间兼容。没有 `.aperture` 文件的素材按 1680×748 处理。

## 4. 覆盖式与外扩式

|  | 覆盖式（默认） | 外扩式 |
| --- | --- | --- |
| 视频的位置 | 填充在画窗内，可调整构图和裁切 | 原视频按原尺寸放在中央，片基加在四周 |
| 画窗内的半透明图案 | 划痕、染色和颗粒可以叠到视频上 | 视频区域由原画占据 |
| 动态 | 画窗和边框随晃动变化 | 边框在预留的范围内移动，视频位置固定 |

制作两种模式共用的素材时，把齿孔、边印和片基放在画窗外，中央保留清楚的透明开窗。外扩按画幅映射片基，必要时重复完整的齿孔段。只应出现一次的编号或条码尽量靠角放置，避免落在边框中部可能重复的区段。

验收时在主预览中切换覆盖式和外扩式，查看齿孔、字样和四边，优先用实际输出画幅。列表缩略图来自原始 PNG，同一素材在两种模式下共用。

## 5. 导入拒绝示例

| 原因 | 应如何处理 |
| --- | --- |
| 画窗宽高超出所选齿孔方向的范围 | 按第 1 节对应方向的区间填入实际开窗尺寸 |
| 图像不是 1920×1080 / RGBA8 | 重新导出符合格式的静态 PNG |
| 中央画窗 >95% 完全不透明 | 降低中心覆盖层的不透明度，保留视频可见性 |
| 画窗外 Alpha≥64 像素不足1024 | 补充真实片边、边印或齿孔等可见元素 |
| APNG、截断、伪装格式、超过32MiB | 用绘图软件重新导出完整的单帧 PNG |

## 6. 授权和版本

请仅导入自己制作或已获得适当授权的素材，本功能不内置 FilmFrame 项目图片。
