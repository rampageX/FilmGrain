AV1 Grain Table 目录（Film Grain Studio v4.6.2）

目录按输出分辨率分类：720p / 1080p / 1440p / 2160p。

Film Grain Studio 会递归扫描所有子目录中的 .tbl / .txt。GUI 选择“现成 Grain Table（影视 / Photon）”后，默认只显示与当前视频最接近的分辨率目录，也可显示全部。

v4.6.2 正式包保留当前整理的一组公开可获取 Grain Table。

主要来源：
Boulder08 / chunknorris
https://github.com/Boulder08/chunknorris

nekotrix / AV1-Photon-Noise-Tables
https://github.com/nekotrix/AV1-Photon-Noise-Tables

Photon-Noise-* 文件主要来自 AV1-Photon-Noise-Tables。影视命名表及部分低/中分辨率 Grain Table 来自公开 Grain Table 集合。

第三方 Grain Table 文件仍受其原始上游项目条款约束；如需再次分发，请同时查看对应上游项目说明。FGS 仅提供 Grain Table 的扫描、分类、选择和调用功能。
