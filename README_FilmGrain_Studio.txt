Film Grain Studio - 使用说明
============================

当前产品版本：v5.0.33；构建 Stable。
像素颗粒直接调整各自原有强度，不再使用额外相对强度混合。

运行：双击 FilmGrain_Studio.exe，或把视频拖到 EXE；启动只导入，不自动编码。
同路径视频被替换或 FFprobe 变化时，请重新选择视频完成探测；执行前检测到变化会停止，原有用户参数保留。
预览窗口提示输入变化时，请关闭窗口、重新选择视频后再打开。
Stable 为便携运行包；Source 为开发源码包，二者用途不同。
请保持运行包内程序、语言文件及资源的相对位置。首次运行按提示指定或安装 FFmpeg/FFprobe 与需要的依赖。
主编码家族选择 AV1、HEVC、H264；CPU 开关切换 SVT-AV1-HDR、x265、x264；启用颗粒默认开启，可关闭后只做插帧、调色等处理。

AV1 不重编码模式仅添加/替换 Film Grain metadata，不重新编码视频；音频独立于容器选择，默认 MP4 转 AAC 256k，MKV 复制音轨。
符合条件的 MP4 静态表和内置预设自动使用 Fast；ISO 核对色彩后选择 Fast 或 compatibility。
MKV、动态外部颗粒表、复杂裁剪时间轴等保留 compatibility。这是处理路径，不是失败。
颗粒预览默认1:1居中，支持随机选点、时间轴及精确时间；各模式四档使用真实参数。
Digital Grain步进0.01；扫描颗粒10%–100%十档；FGSIM提供Light/Normal/Medium/Heavy四档。
AV1内置预设、ISO、TBL提供10%–100%十档强度，默认100%；非100%显示性能提示。
LUT提供0/25/50/75/100%强度，0%关闭效果；普通3D LUT预先调整表强度，组合LUT保留混合并提示。
点击LUT小图可用实际视频帧生成四档对照，默认全图显示，支持随机选点、时间轴和精确时间。
确认档位后，原始帧作为主窗口临时参考图，切换LUT或强度均沿用；再次确认新帧才替换，关闭主窗口后清理。
预览默认跳过开头近黑帧，最多八张采样图；HDR 显示转换不改正式输出。

AV1 烘焙：输入列表旁“AV1 烘焙...”将已有 AV1 颗粒合成为像素，输出 H.264 或 HEVC / AAC。
仅支持普通 SDR；不运行主界面插帧、LUT 或字幕。HEVC Main10 按播放器能力使用，广泛兼容优先 H.264。

文件队列：启动默认统一设置；勾选“独立配置”后，单选文件并用主界面和高级窗口编辑。切换文件自动保留设置，切回统一不删除已有独立配置。
开始后冻结本轮参数，按列表顺序执行；状态列显示等待、处理中、结束、失败、已取消或未执行，选中行自动跟随当前文件。
文件队列与独立配置仅在本次会话保留。

预览编码：勾选进度条前的“预览编码”，输入可编辑的 HH:MM:SS 起始时间（如 01:33:20）及持续秒数（默认 30）。
AV1/HEVC/x264/H.264 NVENC 先按关键帧无损裁剪，再按当前设置处理；实际起点和时长允许偏差。
预览开关、起始和持续为主窗口共用值，文件与模式切换时保持，只有主动编辑才改变。
输出名包含 _PREVIEW_，临时片段在完成/失败/取消后清理；不勾选则处理全片。
速度/质量旁的小箭头打开当前编码方式专用小窗；HDR、插帧、Cinematic Style 的箭头保留各自入口。
“色彩纠正”右键可切换“大界面”。

完整日志位于 Logs；失败时保留 Task 日志和参数。日志目录按钮右键可清理 FGS 日志。
用户配置 FilmGrain_Config.ini 使用时生成，正式包不含个人设置。
功能说明见 README.md；版本变化见 CHANGELOG.md。

Cinematic Style 高级入口打开独立可视化裁剪窗口，上下/左右分别对称调整。
左右非零时，上下0表示不裁上下；自动2.39:1清除手动值。裁剪改变尺寸，加黑边保留尺寸。
调色开启时主按钮为橙色并显示已启用；高级设置不再保留其它页。

四线画幅与可视化窗口共用几何计算；裁剪后的宽高用于自动码率和字幕画布，黑边保留原尺寸。
HDR PRESERVE 与 SDR 调色/LUT 冲突时，无论颗粒开关状态均拒绝；可改用 AUTO/转 SDR 或关闭调色/LUT。
逐行、无颗粒、无插帧的 HEVC HDR→SDR 合并转换与最终编码，省去 HDR 中间视频；调色、LUT、画幅、字幕和音频仍使用当前设置。

高级-音频：音频可选跟随容器（默认）、智能保留、全部复制或全部转 AAC；AAC 可选接近源码率、128/160/192/256/320 kbps。
智能模式可把 AAC 128k 原样保留到 MP4；不兼容音轨按所选码率转 AAC。复制音轨忽略码率选项。
AV1/HEVC/H.264 NVENC 主输出分别提供 Multipass；HEVC/H.264 NVENC 分别提供 B 帧、B 参考与 Lookahead。
悬停控件查看 FGS 推荐值：Multipass 随速度/硬件能力选择；B=4、B 参考=middle、Lookahead 快速16/标准27/高动态32。
HEVC SFE 默认关闭，需要多 NVENC 引擎并通过独立预检；H.264 不支持 SFE。不支持的手动选项明确停止。
H.264 NVENC 输出 High 8-bit，HDR AUTO 转 SDR；不支持保留 HDR10。主流程不再附加 H.264 上传副本。

界面主题：状态栏太阳/月亮单击指定浅色或暗色，右键选择跟随系统／浅色／暗色，自动保存。首次无配置默认跟随系统，升级保留已有选择及其他个人参数。恢复其他参数默认值不改变主题；恢复主题默认请右键选择跟随系统。
主界面及相关应用子窗口、应用右键菜单统一主题，窗体使用 FGS 图标。视频画面、缩略图、颜色结果与导出内容保持原样。系统对话框、系统菜单和标题栏采用 Windows 外观。

NVENC CQ：主界面勾选 CQ 模式，复用“自动”复选框显示推荐数值；也可直接填写 CQ。数值越低目标质量越高，码率和体积随内容变化。
高级页可分别设置 AV1 / HEVC / H.264 CQ 最高码率（默认 80 / 100 / 120 Mbps），可修改或关闭。VBR 与 CQ、各编码器及文件独立配置分别保留。
工具提示支持深浅主题与长文本换行。

底部 GPU、FFmpeg 与硬件能力标签停留约半秒显示提示。选择不可用的 FRUC Vulkan 时显示简明原因并恢复原选项，完整检测信息保留在诊断日志。

预设：在独立配置所在行打开“预设管理”，右键选择五个快捷位置。统一模式保存/应用统一设置，独立模式只作用于选中文件。简单预设不覆盖未包含的高级参数；完整预设包含适用的高级处理配置。
个人预设与快捷绑定保存在 Presets\User；请保留并备份此目录。升级不覆盖用户修改。分享使用管理器导入/导出，资源缺失时按提示重新定位。

CPU：SVT/x265支持VBR与CRF，x264保留VBR及整片多遍。三者Grain调优可独立选择自动/开启/关闭。SVT调校方案主动切换填参考值，preset与RF仍可修改，底层参数只读。SVT/x265暂不开放HDR保留。详见README。

旧版根目录 UserPresets 在首次使用预设时自动迁移到 Presets\User，预设ID与五个快捷绑定一起保留。新目录已有用户数据且旧目录非空时停止预设操作并列出两处路径，不自动覆盖或合并；旧目录损坏也会停止迁移并保留原件。
