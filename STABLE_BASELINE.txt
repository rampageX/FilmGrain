Film Grain Studio formal stable baseline

Baseline:
v4.5.2

Supersedes:
v4.5.1

Major changes:
- Batch Summary now reports Started, Completed, and Elapsed for the complete batch run.
- Timing begins immediately before batch processing starts and ends on entry to the final summary, so enabled interpolation, x264 2-pass work, H.264 upload copies, and other selected post-processing stages are included.
- Started / Completed use local wall-clock time; Elapsed uses UTC ticks and cumulative hours for correct cross-midnight duration reporting.
- GUI and CLI use the same timer implementation in the shared StudioBridge core.
- No AV1 / HEVC / x264 encoding parameters or previously validated processing behavior were changed.

Validation:
The Batch Summary timing change was user-tested successfully on the v4.5.1 stable baseline before this formal v4.5.2 release.

Preserved baseline behavior:
All v4.5.1 AV1 / HEVC / x264 bitrate-policy behavior, Grain / LUT / subtitle / deinterlace / OpenSVPFlow paths, H.264 upload behavior, AAC 256k policy, and standalone tool behavior remain intact.
