Film Grain Studio formal stable baseline

Baseline:
v4.6.1

Supersedes:
v4.6.0

Major changes:
- Adds the dedicated FGS application icon to the WinForms title bar and Windows taskbar.
- Adds independent OpenSVPFlow latest-release maintenance through 01_Update_OpenSVPFlow.bat / Update_OpenSVPFlow.ps1.
- The updater stages and smoke-tests new plugins, backs up the current DLLs, verifies the installed plugins, and rolls back automatically on failure.
- Keeps 00_Setup.bat as the pinned verified first-install path.
- Preserves the v4.6.0 AV1 SFE and interlaced/OpenSVPFlow routing behavior.
- Preserves GUI / CLI synchronization through the shared StudioBridge core.
- Keeps existing AV1 / HEVC / x264 encoding parameters, AAC 256k, Grain, LUT, subtitle, Cinematic, upload, Batch Summary, and MPEG-TS sync behavior unchanged.

Validation:
- Dedicated FGS title-bar and Windows taskbar icons user-tested successfully on Windows 11.
- OpenSVPFlow updater / backup flow user-tested successfully.
- v4.6.0 RTX 4080 SFE and interlaced fallback validation remains unchanged.
