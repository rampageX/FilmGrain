Film Grain Studio formal stable baseline

Baseline:
v4.6.0

Supersedes:
v4.5.2.2

Major changes:
- Adds AV1 NVENC multi-engine Split Frame Encoding (SFE) for Standard and UHQ.
- Detects the usable NVENC engine count dynamically; no GPU model hardcoding.
- Requires grav1synth 0.2.2+ before the SFE checkbox can be enabled.
- Keeps AV1 FAST, HEVC, x264, and AV1 no-reencode SFE disabled by policy based on actual pipeline testing.
- Fixes interlaced input with Interpolation enabled: progressive inputs continue through OpenSVPFlow 60 fps, while interlaced inputs automatically bypass OpenSVPFlow and use the existing field-rate deinterlace path.
- Preserves GUI / CLI synchronization through the shared StudioBridge core.
- Keeps v4.5.2.2 Batch Summary timing compatibility fixes and existing AAC 256k, Grain, LUT, subtitle, Cinematic, upload, and MPEG-TS sync behavior.

Validation:
- RTX 4080: SFE engine count detected as x2.
- AV1 Standard and AV1 UHQ SFE paths user-tested successfully with grav1synth 0.2.2-compatible build.
- Interlaced .ts input with Interpolation enabled user-tested successfully using automatic field-rate deinterlace fallback.
