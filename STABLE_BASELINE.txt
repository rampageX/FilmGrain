Film Grain Studio development stable baseline

Baseline:
v4.4.5

Supersedes:
v4.4.4

Included change:
OpenSVPFlow 60 fps interpolation can now be used together with the H.264
upload-copy feature in both GUI and CLI.

AV1 upload reuses the completed AV1 main output and uses libdav1d to bake
Film Grain metadata to pixels. HEVC + OpenSVPFlow reuses the completed 60 fps
HEVC main output, so interpolation / Grain / LUT / framing / subtitles are not
rendered a second time. Non-interpolated HEVC keeps the existing direct-render
upload path from the original source.

H.264 upload quality rules remain unchanged. x264 Grain continues to use
libx264 / preset slow / tune grain / 2-pass with FPS + resolution + dynamic
bitrate linkage, VBV maxrate = average x3 and bufsize = average x6. Audio is
AAC 256k.

The v4.4.3 OpenSVPFlow A/V sync preservation for .ts / .mts / .m2ts remains
unchanged and is retained as part of this stable baseline.
