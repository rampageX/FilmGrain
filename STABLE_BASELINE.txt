Film Grain Studio formal stable baseline

Baseline:
v4.8.5

Supersedes:
v4.8.4

Formal release:
FilmGrain_Studio_v4.8.5_Stable.zip

Release scope:
- Add HEVC Spatial AQ control in Advanced Settings -> Encoding.
- Spatial AQ choices: 0 / 4 / 8 / 10 / 12 / 15; default remains 8.
- Keep HEVC Temporal AQ as an independent checkbox; default remains enabled.
- Controls affect HEVC main encode only and continue to respect hardware capability detection.

Encoding core:
- Preserve AV1, x264, H.264 upload-copy AQ behavior and all existing Grain, HDR, LUT, interpolation, deinterlace and bitrate logic.
- AAC remains 256k.

Release:
- Windows Server 2022 runner; existing syntax, BOM and CRLF checks preserved.
- GUI status version is v4.8.5.
