Film Grain Studio formal stable baseline

Baseline:
v4.5.2.2

Supersedes:
v4.5.2

Major changes:
- Fixes the Batch Summary timer compatibility issue that could make Started, Completed, and Elapsed all show Unavailable on some Windows / PowerShell environments.
- Timer values are queried independently instead of returning multiple comma-separated values through one PowerShell command.
- Elapsed time is calculated as integer seconds and formatted by BAT as cumulative HH:mm:ss.
- Adds a DATE / TIME BAT fallback so Batch Summary timing remains available when the PowerShell timing query fails.
- GUI and CLI continue to use the same timer implementation in the shared StudioBridge core.
- No AV1 / HEVC / x264 encoding parameters or previously validated processing behavior were changed.

Validation:
The v4.5.2.2 timer compatibility fix was user-tested successfully on both the laptop and desktop systems before formal release.

Preserved baseline behavior:
All v4.5.2 AV1 / HEVC / x264 bitrate-policy behavior, Grain / LUT / subtitle / deinterlace / OpenSVPFlow paths, H.264 upload behavior, AAC 256k policy, standalone tool behavior, and Batch Summary timing scope remain intact.
